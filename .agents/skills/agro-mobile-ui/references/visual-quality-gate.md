# Visual Quality Gate

A screen must be reviewed from a real screenshot.

Reject as P0/P1 when any of these are visible:
- broken or missing map/content
- mojibake or corrupted icons
- technical route/component names
- future/inactive features shown as working
- severe alignment or clipping
- destructive actions visually indistinguishable from primary actions
- controls disproportionate to the approved mockup
- obvious inconsistency between screens
- inaccessible contrast or touch target problems

Do not reject solely for small pixel differences.
The goal is recognizably the same visual system, not pixel-perfect cloning.
